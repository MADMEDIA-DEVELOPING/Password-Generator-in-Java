#HOW TO RUN PROJECT?


1.Descarcă fisirul "generator.java";

2.Crează un folder de desktop si denumește-l;

3.Deschide CMD (Command Prompt) ca Andminstrator;

4.Mergi la folderul creat, salvează-l ca "Patch";

5.Scrie in CMD "cd C:\Users\NumeleTau\Desktop\ProiecteJava";

6.După, dacă nu dă nici o eroare scrie "javac generator.java";

7.La final scrie "java generaor";
